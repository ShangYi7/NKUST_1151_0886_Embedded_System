# NKUST 1151-0886 Embedded System

這個專案整理了 NKUST 1151-0886 嵌入式系統課程中的 8051 Assembly 實驗程式。

## 檔案類型

- `.a51`：8051 組合語言原始碼
- `.hex`：機器碼輸出
- `.lst`：匯編列表檔
- `pdsprj/`：Proteus 模擬專案檔案與備份檔案

## 使用方式

1. 使用 8051 開發環境或相容編譯器開啟 `.a51` 檔案。
2. 編譯並產生 `.hex` 檔。
3. 在 Proteus 中開啟 `pdsprj/` 的專案檔案。
4. 將 `.hex` 檔載入到 8051 晶片，並模擬觀察 LED / DIP switch 行為。

## Proteus 說明

`pdsprj/` 資料夾中的檔案是使用 Proteus 設計的模擬專案，主要用於:

- 電路模擬
- 8051 晶片編譯後的程式驗證
- LED / switch 行為測試
- 專案備份與版本保留

## 備註

這是學習 8051 Assembly 與嵌入式系統基礎的實驗專案，適合做課程記錄、模擬驗證與版本管理。
