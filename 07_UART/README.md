# 8051 雙機 UART 串列通訊實驗 (UART Serial Communication)

NKUST 嵌入式系統（Embedded System）課程實驗專案，使用 8051 組合語言（Assembly）撰寫。實現兩顆 AT89C52 晶片之間的非同步串列傳輸（UART），透過發送端按鍵進行二進位計數發送，接收端接收並解碼驅動 8-Bit LED Bar 顯示。

---

## 一、電路架構與功能設計

本電路包含兩顆 8051 單晶片（AT89C52）：**左側發送端 (U3)** 與 **右側接收端 (U1)**。

```
+-------------------+                          +-------------------+
|     U3 (TX端)     |                          |     U1 (RX端)     |
|                   |                          |                   |
| P1.0 <-- [BUTTON] |                          | P2.0~P2.7 --> [LED-BAR (共陽)]
|                   |                          |                   |
| P3.1(TXD) --------+------------------------> | P3.0(RXD)         |
| P3.0(RXD) <-------+------------------------- | P3.1(TXD)         |
+-------------------+                          +-------------------+
```

### 核心功能特點
1. **雙機自適應單一韌體設計 (Dual-Role Universal Firmware)**：
   - 本程式 `UART.a51` 編譯產生的 `UART.hex` 可**同時載入至 U3 與 U1**。
   - **U3 (發送端)**：偵測到 P1.0 按鍵動作時進行發送；P2 懸空不影響顯示。
   - **U1 (接收端)**：P1.0 懸空為高電位（1），不觸發發送；收到 UART 資料後將取反碼輸出至 P2 點亮 LED。
2. **按鍵控制模式 (U3)**：
   - **短按累加**：每次按下 P1.0，計數值 +1，並立即透過 UART 發送至 U1。
   - **長按連發 (Auto-Repeat)**：按住超過約 0.6 秒後，啟動自動連發模式（每 160ms 遞增 +1 並發送），展示連續傳輸能力。
   - **硬體去彈跳**：具備 20ms 延遲防彈跳邏輯與放手判定，確保計數精確不跳號。
3. **8-Bit 二進位顯示 (U1)**：
   - 接收端將接收到的數值取反碼（`CPL A`），因為 Proteus 中的 LED Bar 陽極接至 +5V（共陽極 Active-Low，低電位 `0` 點亮）。
   - LED 即時以二進位方式點亮（`00000001B` 亮 1 顆、`00000011B` 亮 2 顆 ... 直到 `11111111B` 全亮）。

## 二、硬體腳位配置

| 晶片標號 | 訊號名稱 | 8051 腳位 | 實體 Pin 腳 | 連接元件與功能說明 |
| :--- | :--- | :--- | :--- | :--- |
| **U3 (發送端)** | **KEY_PIN** | `P1.0` | Pin 1 | 按鈕開關（Push Button），按下接地（低電位 0 觸發） |
| **U3 (發送端)** | **TXD** | `P3.1` | Pin 11 | 串列發送腳，連接至 U1 的 RXD (Pin 10) |
| **U3 (發送端)** | **RXD** | `P3.0` | Pin 10 | 串列接收腳，連接至 U1 的 TXD (Pin 11) |
| **U1 (接收端)** | **RXD** | `P3.0` | Pin 10 | 串列接收腳，接收來自 U3 的串列訊號 |
| **U1 (接收端)** | **TXD** | `P3.1` | Pin 11 | 串列發送腳，連接至 U3 的 RXD (Pin 10) |
| **U1 (接收端)** | **LED 0~7** | `P2.0 ~ P2.7` | Pin 21~28 | 連接至 U2 (LED-BARGRAPH-RED) 的 Pin 11 ~ Pin 18 |
| **U2 (LED Bar)** | **VCC (+5V)** | - | Pin 1 ~ 10 | 陽極共接至 +5V 電源（共陽極） |

## 三、UART 通訊設定與暫存器計算

- **通訊模式**：UART Mode 1（8 位元 UART，鮑率可變，1 起始位、8 資料位、1 停止位）
- **鮑率 (Baud Rate)**：`9600 bps`
- **鮑率產生器**：Timer 1 Mode 2（8 位元自動重載模式）

### 暫存器配置
- **`TMOD = 20H`**：設定 Timer 1 為 Mode 2（8-bit 自動重載）。
- **`SCON = 50H`**：`SM0 = 0`, `SM1 = 1`（Mode 1）、`REN = 1`（致能串列接收）。
- **`PCON.7 (SMOD) = 0`**：鮑率不倍頻。
- **`TH1 / TL1 = 0FDH`**：
  $$\text{Overflow Rate} = \frac{11.0592\text{ MHz}}{12 \times 32 \times 9600} = 3 \implies TH1 = 256 - 3 = 253 = \text{0FDH}$$

> [!TIP]
> Proteus 模擬中，請確保 U3 與 U1 的晶片屬性 `Clock Frequency` 設為相同頻率（推薦設定為 `11.0592MHz` 或 `12MHz`）。

## 五、編譯與模擬步驟

1. **編譯組合語言**：
   ```powershell
   asemw UART.a51
   ```
2. **Proteus 載入與執行**：
   - 開啟 `pdsprj/UART.pdsprj`。
   - 雙擊左側晶片 `U3`，在 **Program File** 欄位選取 `UART.hex`。
   - 雙擊右側晶片 `U1`，在 **Program File** 欄位選取同一個 `UART.hex`。
   - 點擊 Proteus 左下角 **Play (開始模擬)**。
   - 點擊 U3 的按鈕，觀察 U1 的 LED Bar 數值累加；長按按鍵觀察連續計數動態。
