# 8051 16 進制計數器與 PC 串列通訊實驗 (UART with PC)

NKUST 嵌入式系統（Embedded System）課程實驗專案，使用 8051 組合語言（Assembly）撰寫。本實驗實現 AT89C52 單晶片與 PC（Proteus Virtual Terminal 虛擬終端機）之間的雙向非同步串列傳輸（UART），並透過共陰極七段顯示器即時呈現 16 進制（0 ~ F）計數結果。

---

## 一、系統架構與電路設計

本電路以 AT89C52 單晶片為核心，透過 Port 2 控制 1 位元共陰極 7 段顯示器，並透過 P3.0 (RXD) 與 P3.1 (TXD) 與 PC 終端機進行 UART 串列通訊。

```
                       +-------------------+
                       |      AT89C52      |
                       |                   |
                       | P2.0~P2.6 (Pin21~27) ---> [ 7SEG-COM-CAT ] (共陰極接地)
                       |                   |
[Virtual Terminal]     |                   |
    TXD (PC送出) ------> | P3.0/RXD (Pin 10) |
    RXD (PC接收) <------ | P3.1/TXD (Pin 11) |
                       +-------------------+
```

### 核心功能特點
1. **16 進制自動循環計數 (Auto Count Mode)**：
   - 開機後自動啟動 16 進制計數（0 -> 1 -> 2 -> ... -> 9 -> A -> b -> C -> d -> E -> F -> 0 循環）。
   - 每步步進時間約 0.6 秒，顯示流暢且易於觀察。
2. **共陰極 7 段顯示器驅動 (Common Cathode 7-Segment)**：
   - 顯示器公共端（COM）連接至 GND，邏輯為**高電位（1）點亮、低電位（0）熄滅**。
   - 採用查表法（`MOVC A, @A+DPTR`）精確輸出 0~F 之 7 段編碼至 P2.0~P2.6。
3. **PC 雙向終端機互動控制 (Interactive Terminal Control)**：
   - **開機選單**：系統啟動時自動於 Virtual Terminal 打印歡迎訊息與操作指南。
   - **即時回傳**：每次數值變更，即時向 PC 終端機發送格式化字串（`Count = X\r\n`）。
   - **鍵盤控制**：
     - `0` ~ `9` / `A` ~ `F`（或小寫 `a` ~ `f`）：直接將計數器指定為該十六進制值。
     - `[空白鍵 Space]` 或 `P` / `p`：暫停 / 恢復自動計數。
     - `+`：單步手動累加（+1）。
     - `-`：單步手動遞減（-1）。
     - `R` / `r`：重置計數值歸零（Count = 0）。

## 四、UART 通訊設定與暫存器計算

- **通訊規格**：UART Mode 1（8 資料位元、1 停止位元、無同位檢查，8-N-1）
- **鮑率 (Baud Rate)**：`9600 bps`
- **時鐘頻率**：`11.0592MHz`
- **計時器配置**：Timer 1 Mode 2（8 位元自動重載模式）
  - `TMOD = 20H`
  - `SCON = 50H`（模式 1，REN=1 啟動接收）
  - `PCON.7 (SMOD) = 0`
  - 計時器重載值計算：
    $$\text{Overflow Rate} = \frac{11.0592\text{ MHz}}{12 \times 32 \times 9600} = 3 \implies TH1 = TL1 = 256 - 3 = 253 = \text{0FDH}$$

## 五、編譯與 Proteus 模擬步驟

### 1. 編譯組合語言
於本目錄下執行：
```powershell
asemw UART-with-PC.a51
```
組譯完成後將產生 `UART-with-PC.hex` 與 `UART-with-PC.lst`。

### 2. Proteus 載入與執行
1. 開啟 `pdsprj/UART-with-PC.pdsprj`。
2. 雙擊晶片 `U1 (AT89C52)`，在 **Program File** 欄位選取 `UART-with-PC.hex`。
3. 點擊 Proteus 視窗左下角 **Play (開始模擬)**。
4. Virtual Terminal 視窗將自動彈出，顯示系統開機訊息與當前計數數值。
5. 觀察七段顯示器是否依序自動跳動顯示 `0` 到 `F`。
6. 點擊 Virtual Terminal 黑色終端畫面，直接於鍵盤輸入指令（例如輸入 `A`、空白鍵、`+`、`-` 等），體驗雙向互動控制。
